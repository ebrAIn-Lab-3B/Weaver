## ebrAIn.lab Weaver 0.1.23

This release strengthens local Markdown authoring and identifies requirements by their repository when working across repositories.

### What is new

- Requirement creation allocates IDs within the selected repository and records reservations in `.weaver/requirement-ids.txt`. Creation previews show the destination and history paths; existing files are not overwritten.
- Cross-repository task references can identify the repository and Git server address. Explicit ports are retained; an omitted port and an explicit port are distinct.
- Rendered Markdown editing applies subsequent input more promptly and handles save, history, and detected edit conflicts more carefully. Detected conflicts retain visible in-session drafts for copying or opening separately.
- Slash-menu accessibility and supported plain-text multiline paste have improved. A local authoring journey, Korean input, document preservation, and representative conflict paths were checked in VS Code; see the task evidence for the exact scope.

### Limits

- Preserve the repository's ID history. IDs deleted before history existed cannot be recovered from current files; a missing history can look like first use. Independent clones and nonparticipating writers can still allocate the same ID. Shared-root allocation is not provided.
- Different server addresses are not automatically treated as the same service. Repositories that share an address and port but differ only by URL path cannot be distinguished by server address alone.
- Input still in transit from the rendered editor or an unfinished IME composition when the editor closes may be lost even when Save is chosen. Automatic draft recovery after close, restart, or crash is not included. Unsupported Markdown remains available in source mode.
- The local creation checks did not include a physically network-disconnected VS Code host. Remote providers and offline-to-online synchronization were not independently verified.
- Marketplace and Open VSX publication are not part of this release.

### Downloads

- `weaver-0.1.23.vsix` for VS Code 1.90 or later.
- `weaver.js`, the command-line tool, for Node.js 20 or later.
