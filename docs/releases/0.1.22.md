## ebrAIn.lab Weaver 0.1.22

Write common Markdown blocks directly in Weaver with a Notion-like editing flow and a slash menu.

### What is new

- Click supported paragraphs, headings, simple lists, and checklist items to edit them. Use Enter to continue writing, and type `/` in an insertion field to choose a heading, bullet list, checklist, or code block.
- Edit ordinary fenced code and simple nested leaf bullets. Paste multiple nonempty plain-text lines into supported existing paragraphs and list items.
- Open requirement documents for rendered editing and return to the requirement view. Source editing remains available for unsupported Markdown.
- Repository summaries show unfinished cards as backlog and active-stage counts instead of a total including completed work.
- Detected editing conflicts keep the active input visible and offer copy or open-as-document actions.

### Not yet

- Nested checklists, formatted nested items, and items with children require source editing. Multiline paste containing blank lines or formatting, or into a new insertion field, also requires source editing. Empty visual spacing is not retained after reopening Markdown.
- Automatic draft recovery after closing a tab, restart, or crash is not included. Save conflict behavior for external edits depends on VS Code settings and the file provider.
- The complete authoring journey with a diagram and all conflict and input timing scenarios has not been verified. Related work remains open in [TASK-123](https://github.com/ebrAIn-Lab-3B/Weaver/blob/v0.1.22/docs/tasks/TASK-123.md), [TASK-124](https://github.com/ebrAIn-Lab-3B/Weaver/blob/v0.1.22/docs/tasks/TASK-124.md), [TASK-125](https://github.com/ebrAIn-Lab-3B/Weaver/blob/v0.1.22/docs/tasks/TASK-125.md), [TASK-126](https://github.com/ebrAIn-Lab-3B/Weaver/blob/v0.1.22/docs/tasks/TASK-126.md), and [TASK-127](https://github.com/ebrAIn-Lab-3B/Weaver/blob/v0.1.22/docs/tasks/TASK-127.md).
- Marketplace and Open VSX publication are not part of this release.

### Downloads

- `weaver.js`, the command-line tool, for Node.js 20 or later.

## ebrAIn.lab Weaver 0.1.22 (한국어)

지원되는 문단과 제목, 단순 목록과 체크리스트를 화면에서 바로 편집하고 `/` 메뉴로 블록을 추가할 수 있습니다. 일반 코드 블록과 단순한 중첩 글머리표도 편집할 수 있으며, 요구사항 화면에서 본문 편집기로 이동할 수 있습니다. 저장 전 충돌이 감지되면 입력 중인 내용을 복사하거나 별도 문서로 열 수 있습니다.

### 아직 없는 것

중첩 체크리스트와 복잡한 서식은 원문에서 편집해 주세요. 빈 줄이나 서식이 포함된 여러 줄 붙여넣기와 새 입력란에서의 여러 줄 붙여넣기도 원문 편집이 필요합니다. 빈 여백은 문서를 다시 열면 유지되지 않으며, 종료·재시작·비정상 종료 후 자동 초안 복구는 제공하지 않습니다. 전체 문서 작성 여정과 모든 충돌 환경의 검증은 계속 진행 중입니다.
