## ebrAIn.lab Weaver 0.1.25

This release adds per-finding reconciliation in Overview, fixes task identifiers on Overview cards, and corrects task Issue links in requirement documents.

### Changes

- Review each Overview mismatch through the shared reconciliation plan, approve one available action at a time, and inspect its result and recheck. Findings requiring a decision offer evidence inspection and source links. Incomplete PR-reference warnings provide a direct evidence-inspection action; the Overview warning remains until its own read is complete.

- Overview cards show the task ID linked to the requirement, even when the Issue title does not include it. When no requirement is linked, the card continues to show the ID from the Issue title.
- Corrected task Issue links in REQ-005 and REQ-022.

### Limits

- Per-finding reconciliation requires a single local workspace folder and the same configured Project as Overview. Automated tests cover the planner and rendered button; a live interactive repair in the extension has not been verified.

- Automatic assignment remains disabled pending its prerequisites. The collaboration and verification limits described in the [0.1.24 release notes](https://github.com/ebrAIn-Lab-3B/Weaver/blob/v0.1.25/docs/releases/0.1.24.md) still apply.
- Marketplace and Open VSX publication are not part of this release.

### Downloads

- `weaver-0.1.25.vsix` for VS Code 1.90 or later.
- `weaver.js`, the command-line tool, for Node.js 20 or later.
