## ebrAIn.lab Weaver 0.1.24

This release makes collaboration participants and configured assignment proposals visible on the Overview, and supports a separately confirmed Issue action.

### What is new

- Cards show task-file participants and selected Project fields, preserving their distinct sources. An explicit human-decision wait in an open task links to its task file.
- Organization-supplied process rules and roster roles can show a state decider and proposed next contributor. Optional configured Project-field conditions restrict proposals; missing or ambiguous inputs are reported rather than guessed.
- For an eligible saved task, a person can review one proposed Issue-assignee or agent-label action. Weaver rereads the relevant Issue, Project, process, roster and task, asks for a fresh Issue-specific execution check and a separate confirmation, then records the attempt and result locally. A configured approval gate still applies.
- Partial PR information is distinguished from confirmed missing closure evidence.

### Limits

- The task-file participant must already match the proposal; this action does not edit the task file. A manual execution check does not guarantee exclusive execution. An unclear write or log outcome must be checked before retrying.
- Automatic assignment remains disabled pending its prerequisites. An agent label may cause an external router to dispatch; inspect execution and the precise action before confirming.
- Decision-wait links cover an explicit task-file status only. Broader current-action, review and merge-request discovery, freshness and conflict handling remain incomplete; an assignee, Project field or open PR does not itself establish a request.
- The live checks covered a confirmed human assignment and one agent delivery and acknowledgement; they do not establish atomic exclusion or automatic execution detection. See the task evidence for scope.
- Marketplace and Open VSX publication are not part of this release.

### Downloads

- `weaver-0.1.24.vsix` for VS Code 1.90 or later.
- `weaver.js`, the command-line tool, for Node.js 20 or later.
